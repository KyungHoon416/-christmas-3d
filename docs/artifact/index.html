남은 과제

아직 완료되지 않은 것

  • TURN 서버가 없어 엄격한 NAT 환경에서는 음성이 연결되지 않을 수 있습니다.
  • 실제 휴대폰(iOS Safari, Android Chrome)과 GPU 기기에서의 FPS 측정이 필요합니다.
  • 로그인은 닉네임 기반 게스트 계정이며, 성인 여부는 자기 신고입니다.
  • 상점·재화·레벨 시스템은 없어서 화면에 "준비 중"으로 표시합니다.
  • 서울 지형은 근사 모델입니다. 정확도를 높이려면 라이선스가 확인된 공간 데이터가 필요합니다.
  • k-carol.mp3는 제공되지 않아, 퍼블릭 도메인 캐럴을 브라우저에서 실시간 합성합니다.
직접 실행

로컬에서 플레이하기

npm install
npm run build
npm start
# → http://localhost:3000

이 페이지 안에서는 게임을 실행할 수 없습니다. 아티팩트는 WebSocket과 WebRTC를 차단하기 때문에, 멀티플레이와 음성이 필요한 게임은 Node 서버에서 실행해야 합니다. 다른 기기에서 마이크를 쓰려면 HTTPS 주소로 배포하세요.
