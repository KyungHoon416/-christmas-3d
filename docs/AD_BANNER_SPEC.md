# 3D ad banner — spec

## Placement (v1)
* **광화문광장**, between the spawn point and the main tree, at the entrance of the winter market:
  position (-14, 0, 26.5), yaw 0.7 rad (faces the spawn / plaza). `locationId = gwanghwamun-main-banner-01`.
* Collision box 9.7 × 1.4 m (shared/ads.js → `adColliders`), added to the region colliders;
  the front (prompt area), the back, the spawn, the tree and the walkway stay free (unit-tested).
* More places: add an entry to `AD_LOCATIONS` (region, position, rotation, slots). Nothing else changes.
  Planned: DDP plaza, Myeongdong entrance, Seoul Plaza event zone, Namsan photo zone, Cheonggyecheon entrance.

## Structure (`client/src/ads/adBanner3D.js`, type `triple`)
| Part | Build |
|---|---|
| Frame | extruded rounded shape 9.2 × 4.65 × 0.7 m, big sweep on the upper left, bevelled, brushed silver PBR (metalness 0.75) |
| Slots | 3 holes in the frame; recessed planes A 5.0×3.1 m (left, main), B 2.6×1.5 (right top), C 2.6×1.5 (right bottom) |
| Lights | warm emissive LED tubes around the frame, every slot, the title and the base; sparkle dots on the sweep (bloom on medium/high) |
| Title | bronze plaque, "CHRISTMAS WORLD SEOUL" (canvas texture) |
| Snow | capsule snow cap + drift on the base |
| Base | rounded plinth with LED edge |
| AD label | "AD · 광고" chip on every slot (ads must be recognisable) |
No point lights are added (emissive only) → negligible cost; `low` quality uses fewer sparkle dots and no shadow casting.

## Slots
* States: ACTIVE / INACTIVE / SCHEDULED / EXPIRED (`slotStatus`). Only ACTIVE shows the ad image; the others show the
  default Christmas promo banner. Schedules are re-checked every 30 s.
* Image: cover-fit into the slot; on load error the procedural slot art is shown.
* Test content: TEST SLOT A/B/C ("AD TEST AREA / SAMPLE BANNER", tree, reindeer, gifts) generated by `client/src/ads/adArt.js`
  and shipped as `client/public/test-assets/ad-slot-{a,b,c}.jpg` (`node scripts/gen-ad-assets.mjs`).

## Interaction
* Prompt "E 광고 보기" (button on mobile) when standing in front (≤ 7.5 m, within the board width).
* Panel: disclosure ("이 게시판은 광고입니다…"), card per slot (image, name, advertiser, description, status, AD tag).
* "사이트 방문" → confirmation dialog with host + full URL → `window.open(url, '_blank', 'noopener,noreferrer')`.
  Nothing opens automatically; only http(s) URLs are accepted (client check + DB rule).
* E / the button / X / Esc closes the panel; only one panel at a time. Hidden during snowball duels.

## AdSense
AdSense code is **never** drawn into the 3D world (policy). Optional site verification for the normal page:
set `ADSENSE_CLIENT` in `shared/ads.js` (or `VITE_ADSENSE_CLIENT`) to `ca-pub-…` → the Firebase build adds the
`adsbygoogle.js` script + `google-adsense-account` meta to `index.html` and writes `ads.txt`. No ad units are placed.
